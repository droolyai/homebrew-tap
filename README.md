# Drooly Homebrew Tap

```bash
brew tap droolyai/tap
brew install --cask maple-city   # Maple City ($DDD) — SFW
brew install --cask wetdrool     # WetDrool — 18+
```

Apps are unsigned for now: right-click → Open on first launch.
